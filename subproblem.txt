Subproblem 1 — Detecting Changes:
We store the last modified timestamp of every file in the watched directory. Every poll cycle we compare current timestamps against stored ones. Three cases:
//
File exists in stored + current, timestamps differ → FILE MODIFIED → upload
File exists in current but not stored              → NEW FILE      → upload
File exists in stored but not current 
             → FILE DELETED  → do nothing (keep backup)
//
Subproblem 2 — The Deletion Problem:
The assignment specifically says do NOT delete backup files when local files are deleted. This is the safe approach — you might accidentally delete a file and want it back. We simply leave the backup on the server untouched.
